# 番剧坞 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps are tracked in task_plan.md.

**Goal:** Complete the designed anime information application and runnable deployment.
**Architecture:** Next.js 14 calls FastAPI /api. PostgreSQL is authoritative, Meilisearch accelerates filtering, Redis caches and limits requests. Independent workers synchronize Bangumi and generate vectors; a tool agent streams grounded answers.
**Tech Stack:** Python 3.11, FastAPI, SQLAlchemy async, PostgreSQL16+pgvector, Meilisearch, Redis, APScheduler, OpenAI-compatible SDK, Next14/TS/Tailwind/shadcn/lucide/SWR.
**Spec:** docs/superpowers/specs/2026-10-19-fanjuwu-design.md plus docs/requirements.txt and design_handoff/README.md.

## Global Constraints
- Visual layout follows handoff; all keys from environment; no unfinished code.
- NSFW filtering is server-side; chat tools force request policy, session client ownership.
- Archive is streamed line by line; writes upsert in batches of 1000.
- Cover ratio 5:7, desktop 6 columns, mobile 2 columns, dark by default.

## Review Focus
- NSFW IDs via direct detail, related items, semantic results, cache and chat history.
- Disjunctive facets must exclude their own filter and include all other filters.
- Archive formats and missing fields; no full archive loaded in memory.
- SSE fragmented chunks, aborted requests, invalid/unowned sessions.
- Empty/unavailable infrastructure and missing optional keys show truthful UI.
